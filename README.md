# Budgie

The ultimate budget companion.

## Installation

We recommend using a python virtual environment.

Assumption:

- creating the virtual environment in home directory
- budgie is cloned in you home directory

```bash
git clone https://github.com/adamsrnmsu/budgie.git
virtualenv budgie-env
source ~/budgie/bin/activate
cd ~/budgie
pip install -e .
```

## Inspiration

Folks enjoy managing budgets with excel spreadsheets.  This is manual, there is no workflow.

Budgie solves this and provides:
    - Trend data
    - A simple planning interface
    - Cost scenario management
    - And is just cooler than a spread sheet
